# Draw Your Africa 🌍

A simple browser-based geography game built with HTML, CSS and JavaScript.

## Run the game

No installation is required.

1. Extract the `draw-your-africa` folder.
2. Open the folder.
3. Double-click `index.html`.
4. The game will open in Chrome, Edge, Firefox, or another modern browser.

## Project files

- `index.html` — game structure and screens
- `style.css` — visual design and responsive layout
- `script.js` — game logic, drag-and-drop, timer, score and levels
- `assets/images/` — optional place for future images

## Game progression

1. East Africa — 60 seconds
2. South Africa — 50 seconds
3. North Africa — 45 seconds
4. West Africa — 40 seconds

A correct placement gives points. Completing a level unlocks the next region. If the timer reaches zero, the player must restart the level.

## Presentation idea

Start the game, demonstrate East Africa, intentionally place one country incorrectly, then place the five countries correctly. Show the timer, score and progress bar. Complete the level to demonstrate the unlock screen.

## Important note

The first prototype uses an interactive visual map area and target zones to demonstrate the gameplay. For a production version, the target zones can be replaced with accurate SVG country boundaries for all African countries.
