# Draw the Map

Browser-based educational geography game using HTML, CSS and JavaScript.

## Run in VS Code
1. Extract the ZIP.
2. Open the `draw-the-map` folder in VS Code.
3. Open `index.html`.
4. Right-click it and choose **Open with Live Server** (if installed), or double-click `index.html`.
5. The game runs in your browser.

## Core interaction
SEE COUNTRY MAP SHAPE → DRAG MAP SHAPE → DROP ON MATCHING LOCATION → SNAP INTO PLACE → NEXT STAGE

The prototype includes 8 East African country-shaped SVG pieces: Uganda, Kenya, Rwanda, Burundi, Tanzania, South Sudan, Ethiopia and Somalia. Names are only shown as fixed target hints; the draggable item itself is a map shape.
